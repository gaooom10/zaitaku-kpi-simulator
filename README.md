# 在宅医療センター KPI・PL 予測シミュレーター

在宅医療センターの前提条件から、12か月／36か月分の実患者数と診療報酬（医科・介護）を予測するWebアプリケーションOSです。

- **公開URL**：https://gaooom10.github.io/zaitaku-kpi-simulator/
- **技術**：外部依存ゼロの単一HTMLファイル（`index.html`）。JavaScript・CSS・計算ロジック・データをすべて内包し、サーバー不要・オフラインでも動作します。
- **認証**：不要（誰でも閲覧・操作できる公開ツール）。

## 主な機能

- センターの状態（新規立ち上げ／立ち上げ済み）による開始月・施設単価立ち上げの切替
- 月あたり新規患者数（1人刻み）＋任意タイミングの増減イベント
- 医療依存度＝平均診療期間の5段階（6/9/12/18/24か月）
- 在宅療養支援診療所/病院 強化型（病床あり／病床なし／なし）＋在宅医療充実体制加算に応じた自動単価
- 単価の任意入力（居宅・施設それぞれ）
- 患者名を使わない月次4項目（デバイス管理患者、追加収益、緊急往診、看取り）による任意の患者構成・業務負荷シミュレーション
- 直近月の追加収益を開始時点患者数で1人あたりに換算し、管理者が明示確認した場合だけ予測患者数へ連動
- 1年／3年予測の切替（グラフは枠内で連動横スクロール）
- 実績（1年前患者数・年間新規・現在患者数、または月別実績）からの平均診療期間の推計

## 計算ロジック

患者数は、平均診療期間ごとの生存曲線（正規分布の重ね合わせから導かれる普遍曲線を平均診療期間で伸縮）を用い、毎月の新規患者コホートと開始時点患者を重ね合わせて算出しています。元となる予測ロジックは香徳会 総合診療プロジェクトのKPI予測プログラムに基づきます。

**注意**：本ツールは概算の試算であり、単価・件数・加算は簡略化しています。算定可否や収益を保証するものではなく、実際の請求額とは差異が生じます。患者個人情報は入力しないでください。

患者構成・追加収益の入力はすべて任意です。追加収益には、居宅・施設の単価へすでに含めた加算や材料収益を重複して入力しないでください。緊急往診・看取り・デバイス管理患者の将来値は、直近月と同じ患者割合が続く前提の参考値であり、施設基準や算定要件を自動判定するものではありません。

入力値はサーバーへ送信・保存せず、ページを再読み込みすると初期値へ戻ります。

## 更新方法

1. `index.html` を編集する
2. 変更をコミットしてプッシュする
   ```bash
   git add index.html
   git commit -m "内容を更新"
   git push
   ```
3. 数十秒〜1分ほどで GitHub Pages に自動反映されます
